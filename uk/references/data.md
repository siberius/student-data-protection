## 4. Модель даних, збір та мінімізація [П]

[П] Модель даних шкільного застосунку ПОВИННА відповідати принципу мінімізації:

- **Ідентифікатори:** Використовуйте синтетичні внутрішні ідентифікатори (UUIDv4) як первинні ключі. Ніколи не використовуйте РНОКПП (ІПН), номер свідоцтва про народження чи паспорта у відкритих посиланнях URL, назвах файлів або клієнтських сховищах.
- **Необов'язкові поля:** Номери телефонів, адреси проживання та особисті фотографії не можуть бути обов'язковими для предметних навчальних тренажерів.
- **Чутливі дані:** Предметні застосунки НЕ МОЖУТЬ зберігати дані про діагнози та особливості здоров'я. Для адаптації інтерфейсу використовується виключно технічний прапорець (наприклад, `font_scale: 1.2` або `extended_timer: true`).
- **Метадані:** Очищуйте файли зображень робіт від метаданих EXIF перед збереженням на сервері.
